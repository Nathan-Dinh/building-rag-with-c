# What is C?

## Asked:
What is C, why was it created, and how is it used?

## My initial guess:
C is a low-level programming language that was developed to make writing assembly code easier and more accessible.

## Answer:

- **What it is:** C is a general-purpose, procedural programming language used to write instructions that a computer can execute. It was developed by Dennis Ritchie at Bell Labs during the early 1970s. It evolved from earlier languages, particularly B, and was developed alongside the Unix operating system. One of its major purposes was to make it possible to develop system software without having to write everything in assembly.

- **How it's used:** C code is written using human-readable syntax and then compiled into machine code that a computer can execute. It is commonly used for operating systems, embedded systems, drivers, compilers, and performance-critical applications.

  There are several C compilers available. Two popular examples are GCC (GNU Compiler Collection) and Clang. Both are free and open-source.

- **How we use it here:** The goal is to explore using C to develop components of a high-performance RAG application. This will help us understand how C can be used for performance-critical operations and how it can integrate with other technologies.

## What I got wrong / what surprised me:

- C is generally classified as a high-level language, although it provides low-level capabilities.
- C wasn't simply created to make assembly easier to write. It was designed to provide a more portable way of developing system software.
- C was instrumental in rewriting Unix, making the operating system less dependent on a specific hardware architecture.
